# v3: Volume launch film (`launchfilm/`)

A 63-second launch film for Volume built from real footage (DVIDS, NASA, Pexels), one
narrator and a CC BY 4.0 music track ("Uprising" by Scott Buckley, 90 BPM), cut on a single
cue sheet. The narration is Microsoft's `en-US-GuyNeural` neural voice (best of four scored
takes per line) and can be swapped for a recorded human read by dropping WAVs into
`narration_recorded/`. Nothing in the picture is generated: no AI imagery, no procedural
graphics beyond type and the client's own logo file. Readable brand marks in the footage
are blurred.

```bash
sudo apt-get install -y ffmpeg fonts-inter
pip install --break-system-packages numpy scipy opencv-python-headless pillow pyyaml soundfile
# narration engine + scoring: see launchfilm/BUILD_NOTES.md (separate env, NARRATOR_PYTHON)
python3 -m launchfilm.render --all        # fetch sources, mix, render 16:9 + 9:16, credits, contact sheets
```

Outputs land in `out/` (git-ignored): `volume_launch_16x9_1080p.mp4` (1920x1080, 63.0 s) and
`volume_launch_9x16_1080x1920.mp4` (1080x1920), 24 fps H.264 High + AAC 48 kHz, mixed to
-14 LUFS / -1 dBTP. Large media is never committed; `launchfilm/sources.yaml` lists every
clip's URL and quoted license, and the render downloads them into `cache/`.

| file | what it is |
|---|---|
| `launchfilm/sources.yaml` | every external input: URL, item page, quoted rights statement, access date |
| `launchfilm/cuesheet.json` | the edit: shots, crops and blur boxes per shot, narration script and timing, closing lines, music segments, reveal, end card |
| `launchfilm/CREDITS.csv`, `CREDITS.md` | generated from the manifest + actual uses (every clip, narration line, music cue) |
| `launchfilm/BUILD_NOTES.md` | script, pipeline, commands, rights decisions and rejected sources |
| `brand/volume-logo.svg` | the client's logo, rendered as-is |

The end card URL is one editable field (`endcard.url` in the cue sheet). The music license
requires this credit wherever the film is published (for YouTube, in the description):
*'Uprising' by Scott Buckley - released under CC-BY 4.0. www.scottbuckley.com.au*.
Placements that can't carry the credit need the composer's paid license.

# v1: The World, Delivered — a history of logistics

A 2-minute documentary-trailer film (1920x1080, 60 fps, H.264 + AAC) where
**every pixel and every sample is generated by code in this repo**. The film uses
no images, footage, textures, samples, SoundFonts or plugins. The only external
inputs are the system fonts that ship with the VM (Noto Serif Display, Noto Serif
and Inter), which are used for the title cards.

## Re-rendering

```bash
# system deps (Ubuntu)
sudo apt-get install -y ffmpeg python3-dev python3-cairo libcairo2-dev fonts-noto-core
pip install --break-system-packages numpy scipy opencv-python-headless pillow pycairo

# full film: renders every shot, synthesizes the score, muxes, encodes the delivery copy
python3 -m logistics.render --all
#   build/history_of_logistics_master.mp4   CRF 21 master (~345 MB; the film grain is expensive)
#   build/history_of_logistics.mp4          two-pass 6.5 Mbit/s delivery (~100 MB)
python3 -m logistics.render --deliver --vbitrate 10M   # re-encode the delivery copy only

# score only
python3 -m logistics.audio                 # -> build/score.wav (48 kHz float stereo)

# iterate on the picture
python3 -m logistics.render --stills 12,40.5,88     # PNG stills at given seconds -> build/stills/
python3 -m logistics.render --shots sail,port       # re-render only those shots
python3 -m logistics.render --mux                   # re-mux existing shots + score

# contact sheet (12 frames)
python3 -m logistics.contact build/history_of_logistics.mp4 build/contact_sheet.png
```

A full render takes about 25 minutes on 4 cores. Neither MP4 is committed because
both exceed 50 MB. Frames are rendered in parallel
(`--workers`) and piped straight into ffmpeg, one segment per shot.

## One cue sheet drives both picture and score

`cuesheet.json` is the single source of truth. It sets 80 BPM in 4/4, so one bar is
3.0 s and the film is 40 bars (120 s). Every position in the sheet is given in bars.

| key | used by the picture | used by the score |
|---|---|---|
| `shots` | cut points and color grade per shot | section changes |
| `impacts` | exposure punches, camera shake, chromatic kick, lightning strobes | taiko, sub-boom, braam and crash hits |
| `risers` | camera push-ins and building glow | noise and pitch risers, reverse cymbals |
| `silences` | black frame (the "breath" before the final hit) | all layers gated to silence |
| `hush` | the fog-bound 1956 quay | orchestra drops out, leaving celesta and heartbeat |
| `titles` | dated title cards, timed to land on downbeats | — |
| `chords`, `motif`, `motif_statements` | — | harmony and the recurring theme |
| `intensity` | particle density, bloom and shake per bar | layer density and dynamics |

`logistics/cues.py` turns the sheet into a `FrameInfo` for every frame: the bar and
beat, local shot time, beat pulse, decaying impact envelope, lightning and silence.
Scene functions read that value directly, so a cut or hit moved in the JSON moves in
both the picture and the audio on the next render.

## The score (`logistics/audio.py`)

Everything is synthesized with numpy/scipy:

- **Instruments:** PolyBLEP band-limited saws; a Karplus-Strong oud; a breathy ney
  flute (noise through resonant bandpass plus a sine core with vibrato); an additive
  celesta; detuned 7-voice supersaw strings; a filtered-saw brass section; a choir
  made of supersaws through formant bandpasses; spiccato ostinati; taiko, snare, hats
  and crashes built from noise and pitched sine sweeps; sub-booms, braams and risers.
- **Diegetic sound design,** also synthesized: desert wind, thunder, a galleon horn,
  a train whistle and piston chug, the 1956 container clang, jet roar and whooshes.
- **Harmony:** D minor with an Andalusian cadence (Dm–C–B♭–A). A single 4-bar motif
  passes from a lone ney (bar 1) to the oud (bar 2), horns (Rome), the celesta
  (the 1956 hush), full strings (air freight) and finally tutti brass, strings and
  choir an octave down (bar 33).
- **Mix:** two custom stereo impulse responses (a hall and a room) with
  frequency-dependent decay, generated in code and fed by per-bus sends through FFT
  convolution; an RMS glue compressor; and tanh soft-clipping. The final hit is
  kept out of the compressor so it is the loudest moment of the film.

Arc: a lone flute over wind, then plucked oud and hand drums, horns and war drums for
Rome, a storm with thunder hits, driving steam-engine ostinati, a sudden **hush** in
1956 with celesta, then a heartbeat under the lifting box until the container lands on a huge clang, then a
build through air, port and globe to a full orchestral swell. The drone caravan
leads into one beat of silence, followed by the final hit and the title card.

## The picture (`logistics/gfx.py`, `post.py`, `text.py`, `scenes/`)

- **Drawing:** PyCairo vector graphics at full 1080p. A 2.5D camera (`Cam`) has depth
  parallax, dolly, zoom, roll and impact shake. Procedural value noise and fBm
  generate dunes, clouds, smoke, waves and fog.
- **Light:** a separate emissive `Glow` buffer (fine, soft and streak components)
  holds fire, lanterns, headlights, sodium lamps and LEDs.
- **Post:** two-tier bloom, ACES filmic tonemapping, a per-shot color grade (desert,
  dawn, fire, storm, steam, fog, golden, night, future), chromatic aberration,
  vignette, animated film grain and a 2.39:1 letterbox.
- **Titles:** tracked serif type with date rules, soft glow and scrims, timed from the
  cue sheet.

## Layout

```
cuesheet.json            tempo map, cuts, hits, titles, harmony (shared by picture and score)
logistics/cues.py        cue sheet → per-frame timing info
logistics/audio.py       the whole score and sound design → build/score.wav
logistics/gfx.py         cairo helpers, camera, noise, glow buffer
logistics/post.py        tonemap, grade, bloom, grain, letterbox
logistics/text.py        title cards
logistics/scenes/        one function per shot (ancient, industrial, modern, common)
logistics/render.py      parallel renderer, per-shot encode, mux
logistics/contact.py     contact sheet
```
